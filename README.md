# Lọc file kiểm kê IMEI – DDV 621 Âu Cơ

Công cụ chạy trên trình duyệt: thả file xuất từ hệ thống (bản đầy đủ) vô, tự loại **máy Demo, CCDC, đồng hồ/vòng tay, tai nghe/loa, phụ kiện**, rồi xuất lại file Excel để bắn IMEI kiểm kê.

## Cách dùng
1. Mở trang (GitHub Pages) hoặc bấm đúp `index.html`.
2. Kéo thả file `.xlsx` vô.
3. Bấm **Tải file Excel đã lọc**.

- Bỏ tick nhóm nào thì nhóm đó được giữ lại.
- Ô "Từ khóa loại thêm": gõ thêm từ cần loại, cách nhau bằng dấu phẩy.
- Dữ liệu xử lý ngay trên máy, không gửi đi đâu.
